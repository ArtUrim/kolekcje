Kolekcje - Collections Management Application

A Vue.js/Nuxt.js application for organizing personal collections including books, music albums, and movies.

About

Kolekcje is a comprehensive collection management system that helps users organize and track their personal collections. The application currently focuses on book management with plans to expand to music albums and movies.

Look

The main interface of Kolekcje showing the clean, intuitive design for managing your book collections with easy navigation and search functionality.

Features

  • Book Management: Add, search, edit, clone, and organize your book collection with comprehensive metadata support
  • Advanced Search & Filtering: Filter by title, author, publisher, series, language, format, and more
  • Detailed Book Information: Track ISBN, subtitle, publication dates, original title, translator, format (hardback, paperback, ebook, etc.), page count, genres, series, labels, and personal notes
  • Multi-language Interface: Available in English, Polish, and Italian with easy extension to additional languages via Vue i18n
  • Responsive Design: Works seamlessly on desktop and mobile devices with adaptive layout
  • External Data Integration: Automatic book metadata lookup via ISBN databases, DuckDuckGo, and Goodreads
  • Data Validation: JSON Schema validation ensures data integrity when adding or updating books
  • Flexible Table Views: Customizable column selection and table presets for personalized viewing experience
  • Expandable Text Fields: Smart text display with expand/collapse functionality for long descriptions and notes

Architecture

The application follows a modern three-tier architecture:

  • Reverse Proxy Layer: nginx handles HTTP traffic routing and load balancing between frontend and backend services
  • Frontend Layer: Nuxt.js (Vue.js 3) serves the user interface with server-side rendering capabilities
  • Backend Layer: Flask RESTful API manages business logic and data operations
  • Data Layer: MariaDB provides persistent storage for collection data

Future Enhancement: Redis caching layer is planned to be added for enhanced performance.

Technology Stack

Frontend

  • Frontend: Vue.js 3 with Nuxt.js
  • Internationalization: Vue i18n
  • Styling: Scoped CSS with responsive design

Backend

  • API Framework: Python Flask 3.1 with Gunicorn WSGI server
  • Database Driver: MariaDB connector (v1.1.11)
  • Data Validation: jsonschema for book data validation
  • External Services Integration:
    • DuckDuckGo search API for book information lookup
    • ISBN database integration for automatic metadata retrieval
    • Goodreads API support for book details
  • Testing: pytest framework with comprehensive test coverage

Database

The MariaDB database is designed to efficiently store and manage collection data with a normalized schema ensuring data integrity and scalability. The schema supports books, music albums, and movies with the following key entities:

  • Books: Core table storing ISBN, title, subtitle, release dates, format, pages, descriptions, and notes
  • Authors: Multi-language support with nationality, birth/death dates, and descriptions
  • Publishers: Publisher information with webpages and descriptions
  • Series: Book series tracking with descriptions and notes
  • Genres: Categorization system for collections
  • Labels: Custom labeling for personal organization
  • Language Support: ISO language codes for multi-language collections

The database uses many-to-many relationships (via junction tables like bookAuthors, bookGenres, bookPublishers, bookLabel) to support multiple authors, genres, publishers, and labels per book.

Setup

Docker Deployment

The application can be deployed using Docker Compose with all required services:

docker compose up

This command starts the following services:

  • MariaDB: Database server for data persistence
  • Nuxt.js Frontend: Vue.js 3 application with SSR capabilities
  • Flask Connector: Python RESTful API backend
  • nginx: Reverse proxy for routing HTTP traffic
  • Adminer: Database management interface (available on port 8080)

Raspberry Pi Installation (moode.audio Integration)

Development Setup

For local development, navigate to the frontend directory and install dependencies:

cd front
npm install
npm run dev

The development server will start on http://localhost:3000.
